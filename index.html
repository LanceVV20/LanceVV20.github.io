05

Automation

The case study comes with a Playwright + TypeScript suite using the Page Object Model. It runs on every push and every Monday through GitHub Actions.

Known bugs live in the suite as test.fail() regression checks. The pipeline stays green while a bug is open, and the moment a fix lands, the test flags it so the ticket can be closed.

test('TC-017 complete a purchase end to end', async ({ page }) => {
  await checkout.fillInfo('Juntue', 'Dela Fuente', '2432');
  await checkout.finishButton.click();
  await expect(checkout.completeHeader)
    .toHaveText('Thank you for your order!');
});
